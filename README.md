# 🏛️ get-more-perspectives-skill — 虚拟顾问团多视角决策洞察

> **VStart · 文森策 出品**
> 
> 在做出重大决定前，召集 3-5 位拥有鲜明立场的虚拟专家顾问，从落地执行、风险风控、长远格局、用户感知和商业算账 5 个维度独立审视方案，帮你提前排雷、找准机会，交付带有低成本探针实验与不可逾越止损红线的决断方案。

## 🌟 为什么需要这个技能？

面对重大选择（如 Offer 抉择、技术架构重构、产品定价调整、业务转型等），决策者往往容易面临两种困境：
1. **一个人的思维盲区**：自己想方案容易陷入“证实偏见”，只看对自己有利的理由，忽视了致命隐患；
2. **身边朋友的一团和气**：周围人往往不好意思当面泼冷水、说重话，导致潜在风险被掩盖。

`get-more-perspectives-skill` 为你模拟由资深专家组成的专属智囊团：
- ⚙️ **执行者 (The Operator)**：评估落地可行性、排期卡点与第一步具体动作。
- 🛡️ **质疑者 (The Skeptic / 首席杠精)**：进行事前失败推演 (Pre-Mortem 逆向排雷)，死磕隐性假设与最坏情况。
- 🔭 **远见者 (The Visionary)**：评估 3-5 年战略复利、非对称机会与时代技术趋势。
- 👤 **客户代言人 (The Customer Voice)**：捍卫真实用户体验，区分是用户真痛点还是自己自嗨。
- 📊 **算账专家 (The Quant)**：算清真实投入产出比 (ROI)、现金流底线与机会成本。

各顾问先独立发表见解，随后通过**观点张力矩阵 (Tension Matrix)** 提炼本质权衡，输出附带 72 小时探针实验与明确止损红线的决策建议。

## 🎯 常见使用场景

- **二选一或多选一纠结**：“拿到两个 Offer 不知道怎么选”、“在稳妥方案与激进方案之间犹豫不决”
- **重大方向审视**：“该不该把现有单体架构拆成微服务”、“这个 SaaS 产品的免费版要不要取消”
- **专家挑刺与事前排雷 (Pre-Mortem)**：“从不同专业角度帮我看看这个方案有什么漏洞”、“如果专家来看会挑出什么毛病”
- **商业化与转型评估**：“这个新业务到底能不能做”、“新产品该如何定价”、“这个创业方向有没有坑”

## 📦 全平台部署指南 (Universal Deployment)

本技能采用标准 **Agent Skills 开放标准 (`SKILL.md`)** 设计，零代码、零第三方依赖，纯粹依靠大模型认知框架驱动，适用于所有主流 AI 平台：

### 1. 小红书 Red Skill 平台
直接将本文件夹（或打包为 `.zip`）上传至创作者中心，或者直接上传 `SKILL.md` 单文件：
- **技能名称**：`虚拟顾问团多视角决策洞察`
- **功能简介**：
  > 面对选Offer、业务转型、定价调整或重大方案纠结？为你召集执行者、质疑者、远见者、用户代言人和算账专家组成专属顾问团。独立挑刺审视方案，输出观点张力矩阵、72小时探针实验与止损红线，助你穿透盲区从容决断。
- **场景标签**：`职场成长`、`商业思考`、`效率工具`、`思维模型`、`AI应用`

### 2. 本地 Agent / IDE 环境 (Claude Code, Cursor, Windsurf, Antigravity)
放置于 Agent 全局或项目的 skills 目录下即可自动识别：
- 全局路径：`~/.agents/skills/get-more-perspectives-skill`

### 3. 任何网页端 AI (ChatGPT, Claude, Kimi, 豆包等)
直接将 `SKILL.md` 的内容作为自定义指令 (System Prompt) 或开篇提示词发送给 AI 即可开始使用。

## 💡 实战决策四大原则

1. **单向门与双向门区别对待**：可逆决策（双向门）不做无谓争论，用 72 小时低成本实验拿真实数据；不可逆决策（单向门）必须深度排雷、做事前失败推演。
2. **第一轮坚决独立交卷**：顾问发言严禁提前互相附和，质疑者必须足够尖锐，远见者必须敢于看到长远机会。
3. **把争论提炼为本质权衡**：不搞“各打五十大板”的和稀泥，清晰梳理“先发优势 vs 试错成本”、“短期变现 vs 长期口碑”等底层权衡。
4. **提前设立止损红线 (Kill Criteria)**：在行动第一天写清撤退条件，彻底避免陷入沉没成本陷阱。
